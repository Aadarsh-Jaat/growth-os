# Growth OS - Personal Growth Operating System

A comprehensive life management and growth tracking application.

## Features
- Task Management
- Habit Tracking
- Fitness Tracking
- English/IELTS Learning
- Career & Job Preparation
- Business Management (Wildcore Perfume & Transport)
- Investment & Savings Tracking
- AI Coach
- Dark/Light Mode
- Mobile Responsive

## Setup Instructions

1. Clone the repository
2. Run `npm install`
3. Create a Firebase project and enable Authentication & Firestore
4. Copy your Firebase config to `.env` file
5. Run `npm start`
